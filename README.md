# Nearby

Nearby is a privacy-first hyperlocal social discovery platform.

The platform helps people discover and participate in nearby activities without requiring existing social connections.

## Technology Stack

### Frontend

- React
- Vite
- React Router
- Redux Toolkit
- Axios
- Tailwind CSS

### Backend

- Python
- FastAPI
- SQLAlchemy
- Alembic

### Database

- PostgreSQL
- PostGIS
- pgvector

### Infrastructure

- Docker
- Redis
- GitLab CI/CD
- Cloud deployment

### AI

- LLM
- Embeddings
- Recommendation System
- AI Moderation
- AI Agents
